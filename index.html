System Architecture

1. User Interface

Built with HTML & TailwindCSS. Captures input and updates the DOM dynamically without page reloads.

2. Core Engine

JavaScript intercepts payloads, formats arrays, bridges the UI, and acts as the central logic processor.

3. Memory Bank

Simulates a backend database using browser localStorage. JSON is serialized & persisted.

How Persistence Works on Static Hosts

Because GitHub Pages acts as a static host (preventing Python backend scripts from running directly), this architecture flawlessly mimics a binary file handling system directly within the client's memory bank using serialized JSON formatting. Your data is instantly retained locally across browser sessions.
