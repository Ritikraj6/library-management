1. User Interface (UI)

Built entirely with static HTML & TailwindCSS. It captures user inputs (like adding a book or issuing an asset) and listens for interactions without needing a server reload.

2. Processing Engine

JavaScript intercepts the inputs, formats the data into JSON objects, filters arrays for searches, and manipulates the DOM in real-time to reflect changes.

3. Data Persistence

Because GitHub Pages is a static host, the backend binary file handling is simulated using the browser's localStorage API. Data is serialized to a string and safely saved across sessions.
